# ContactsManager

## Description
Projet Java permettant de gérer une liste de contacts.
Chaque contact possède un nom et un numéro de téléphone.

## Fonctionnalités
- Ajouter des contacts avec `addContact()`
- Rechercher un contact par nom avec `searchContact()`
- Capacité de stockage jusqu'à 500 contacts
